# Install Snapdraft

## Requirements

Snapdraft is distributed for macOS. Download the latest release from:

https://github.com/ranyitz/snapdraft/releases

## Install

1. Download the latest `.dmg`.
2. Open the downloaded disk image.
3. Drag `Snapdraft.app` into `Applications`.
4. Launch Snapdraft from `Applications`.

## First Launch

If macOS blocks the app on first launch, open `System Settings`, review the security prompt, and allow Snapdraft to open.

If the app still does not open, create an issue and include your macOS version, Snapdraft version, and any visible error text.

## Uninstall

Quit Snapdraft, then remove `Snapdraft.app` from `Applications`.
