# Snapdraft

Snapdraft is distributed from this public repository for downloads, installation notes, update metadata, and issue tracking.

## Download

Download the latest macOS build from the [Snapdraft Releases page](https://github.com/ranyitz/snapdraft/releases).

## Install

1. Download the latest `.dmg` release.
2. Open the disk image.
3. Drag `Snapdraft.app` into `Applications`.
4. Launch Snapdraft from `Applications`.

If macOS blocks the first launch, open `System Settings`, review the security prompt, and allow Snapdraft to open.

## Updates

Snapdraft uses Sparkle for in-app updates. The public appcast is available at:

https://ranyitz.github.io/snapdraft/appcast.xml

The appcast is currently a valid placeholder feed. Future releases will add signed update items and artifacts through release automation.
